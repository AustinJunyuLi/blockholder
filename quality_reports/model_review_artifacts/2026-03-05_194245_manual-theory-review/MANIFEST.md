# Manifest

This manual bundle is theory-focused and intentionally excludes generic repository clutter.

## Included

- `draft_v3.tex`
- `draft_v3.pdf`
- `bibliography.bib`
- `Makefile`
- `numerical/`
- `numerical_output/`
- `quality_reports/paper_review_draft_v3.md`
- `.context/GIT_STATUS.txt`
- `.context/GIT_HEAD.txt`
- `AUTHOR_CONTEXT.md`

## Purpose

- `draft_v3.*`: current manuscript
- `bibliography.bib`: literature context
- `numerical/`: current model implementation and solution logic
- `numerical_output/`: current figures and tables
- `paper_review_draft_v3.md`: current critique and failure points
- `.context/*`: repository state snapshot
- `AUTHOR_CONTEXT.md`: concise statement of what GPT Pro should optimize for

## Excluded

- prior auto-generated GPT Pro artifacts
- unrelated session logs and planning notes
- presentation-only materials
- caches and repository metadata

The aim is to keep GPT Pro focused on the theory paper rather than on generic project detritus.
