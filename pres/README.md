# Presentation: Liquidity, Activism Disclosure, and Takeover Premia

## Overview

Two parallel 40-minute decks sharing one narrative spine:

- **`presentation.tex`** — academic Beamer deck (Metropolis theme; 18 core
  slides + backup slides with bidirectional hyperlinks for Q&A).
- **`make_pptx.py`** → **`blockholder_seminar_40min.pptx`** — business-format
  deck (navy/charcoal consulting style, action headlines, figure-led).

## Structure

```
pres/
├── presentation.tex                 # Beamer deck (Metropolis theme)
├── slides.bib                       # Beamer bibliography
├── make_pptx.py                     # PPTX generator (python-pptx)
├── blockholder_seminar_40min.pptx   # generated business deck
├── figures/                         # slide-only figure variants (pyfig)
│   ├── fig_disclosure_slopes.pdf
│   ├── fig_sensitivity_panel1.pdf
│   ├── fig_sensitivity_panel2.pdf
│   └── fig_noisy_rumor.pdf
└── pptx_assets/                     # 300-dpi PNGs rasterized at build time
```

Shared manuscript figures are **not** duplicated here: the Beamer
`\graphicspath` and the PPTX builder pull them straight from
`../numerical_output/` (canonical pyfig output) and `../empirics/output/`
(Facts 1–2). The four slide-only variants above are generated by
`python -m pyfig.slide_figures` (also wired into `make figures`).

## Theme

Metropolis (`\usetheme[progressbar=frametitle,...]{metropolis}`), included
with TeX Live. Accent colors match the paper's figure palette
(`pyfig/style.py`): blue `#4477AA`, teal `#44AA99`, rose `#CC6677`.
Fira Sans is used automatically when installed; otherwise Metropolis falls
back to the default sans family. The PPTX uses a navy/charcoal consulting
palette (`NAVY #1F3A5F`, charcoal ink, hairline rules) with the same Tol
accents for action-coded chips.

## Compilation

### Step 1: Generate figures (from the project root)

```bash
make figures          # manuscript figures + the four slide-only variants
```

### Step 2: Compile the Beamer deck

```bash
cd pres
xelatex presentation.tex
biber presentation
xelatex presentation.tex
xelatex presentation.tex
```

### Step 3: Build the PPTX deck

```bash
.venv/bin/python pres/make_pptx.py    # requires python-pptx + pdftocairo
```

Fact 1/2 headline numbers are read from `empirics/output/*.csv` at build
time, so re-running after an event-study refresh updates the evidence
slides automatically.

## Navigation System (Beamer)

Core slides contain clickable links (e.g., `↗ Sensitivity analyses`) that
jump to the corresponding backup slide. Each backup slide has a
`← Return` link back to the originating main slide. Uses `\hypertarget`
and `\hyperlink` commands.

## Audience Calibration

The Beamer deck is calibrated for two supervisors:

- **Prof. Alex Gorbenko** (UCL): M&A auctions, corporate control, law & finance.
  Disclosure policy and testable predictions are treated as first-class results.
- **Prof. Ming Yang** (UCL): Rational inattention, information design.
  Propositions are stated formally; Bayesian inference mechanics receive careful treatment.
