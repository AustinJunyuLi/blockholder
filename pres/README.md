# Presentation: Liquidity, Activism Disclosure, and Takeover Premia

## Overview

20-25 minute Beamer presentation (19 core slides + 29 backup slides) with
bidirectional hyperlink navigation for Q&A.

## Structure

```
pres/
├── presentation.tex       # Main Beamer file (core + backup)
├── slides.bib            # Bibliography (committed file)
├── *.sty                 # UCL Beamer theme (committed files)
├── banners/              # UCL banner graphics (committed PDFs)
├── figures/
│   ├── solver.R          # Full equilibrium solver (R port of Python)
│   ├── theme_pres.R      # Presentation-specific ggplot2 theme
│   ├── render_all.R      # Master orchestrator for all figures
│   └── fig_*.pdf         # Generated PDF figures (18 files; 11 referenced on slides)
└── README.md
```

## Dependencies

### R packages

```r
install.packages(c("ggplot2", "dplyr", "readr", "tidyr", "latex2exp", "scales"))
```

### LaTeX

- XeLaTeX + biblatex/biber
- Beamer with UCL theme (theme files committed in `pres/`)

## Compilation

### Step 1: Generate figures

**Option A — From scratch (uses R solver):**
```bash
cd pres/figures
Rscript render_all.R
```

**Option B — From pre-computed CSV data (faster):**
```bash
cd pres/figures
Rscript render_all.R --use-csv
```

Option B reads CSV files from `../../numerical_output/data/` (generated by the
Python pipeline via `make data` from the project root).

### Step 2: Compile slides

```bash
cd pres
xelatex presentation.tex
biber presentation
xelatex presentation.tex
xelatex presentation.tex
```

## Navigation System

Core slides contain clickable links (e.g., `↗ Sensitivity analyses`) that
jump to the corresponding backup slide. Each backup slide has a
`← Return` link back to the originating main slide. Uses `\hypertarget`
and `\hyperlink` commands.
