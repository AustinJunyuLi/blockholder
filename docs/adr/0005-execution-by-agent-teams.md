# Tickets are executed by bounded parallel Agent teams, not the dynamic Workflow tool

Standing user preference (memory: prefer-agent-teams-over-workflows) and the 2026-08 orchestration review: ≤12 agents per stage, finder ≠ verifier, verifiers prompted to refute (WRONG / MISCITED / UNCHECKED), executed checks wherever one exists, one retry with evidence, commit at the end of each stage. Full-text reading goes through ego-browser (Wiley/OUP/NBER open; JFE via working-paper versions; SSRN/WRDS need the author to log in). The author is pinged whenever a decision or a login is theirs.
