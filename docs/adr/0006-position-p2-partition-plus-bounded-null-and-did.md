# The position is P2 (the disclosure rule as the market's partition), carrying P4's bounded null and P4's matched DiD as a run result

The ticket-03 tournament ranked five proposals; P2 (partition, whitespace W3) won on Borda with two of three first-place votes, P4 (Feb-2024 × control outcome) took the highest raw total and Judge 3's first place, and two judges named the package of P2's model with P4's empirics as the natural paper. The author takes that package in a reduced form: P2 is the identity and the theory, P4's bounded null and P4's matched DiD on the twelve-month bid hazard (never-13D controls) are run for December, and P4's premium hand-collection is cut. P4 alone was rejected because its anchor is crowded and its companion model thin, so the paper would lose the identity triad ADR-0004 protects; the full package "before December" was rejected on deliverability — P4's whole empirical track is ~9–13 weeks and would put the theory rebuild and the empirics on the same critical path. Consequence: the December package is P2's partition theorem plus a timing-split headline, a bounded null and a matched DiD, with the causal premium specified only.
